# LLM Router Workspace

> Skrip peluncur untuk menjalankan beberapa router LLM secara bersamaan dengan isolasi cookie, base URL, dan database.

## ✨ Fitur

- 2 router paralel
- Isolasi cookie dan database
- Start-up otomatis
- Catatan arsitektur proxy TLS MITM lokal

## 🛠 Tech Stack

"Windows Batch" "PowerShell" "Node.js" "SQLite"

## 🚀 Menjalankan

```
router.cmd
```

## 📌 Catatan

Proyek ini merupakan bagian dari portofolio pribadi. Kode disusun untuk kebutuhan nyata,
bukan sekadar demo, sehingga sebagian konfigurasi spesifik lingkungan mungkin perlu
disesuaikan sebelum dijalankan.
